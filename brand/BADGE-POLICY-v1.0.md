# Aftergraph README Badge Policy v1.0

Dynamic badges are allowed only when they communicate live, auditable state.

Allowed: `build` · `tests` · `coverage` · `release` · `license` · `security` · `docs` · `conformance` · `SBOM` · `provenance`

1. Maximum 6 badges in the README front door.
2. Secondary badges belong in a Status section.
3. Never use static images to imply passing tests, security, release, or conformance.
4. Every state badge must link to the evidence surface it summarizes.
5. Scientific claims belong in research evidence, not decorative badges.
6. AIE conformance badges reflect AIE evidence only.
