# Aftergraph

> **Provisional home of ABDE Intelligence — infrastructure for governed autonomous intelligence.**

Aftergraph is the current GitHub working namespace for an ecosystem spanning governed runtime control, durable execution, work inference, institutional semantics, scientific evaluation, and cross-repository governance.

**Brand status:** `Aftergraph` / `ABDE Intelligence` remain **provisional and not trademark-cleared**. The visual rollout is migration-safe and does not force irreversible renames.

## Evidence boundaries

Runtime evidence, execution evidence, standards conformance, and scientific evidence remain distinct. No repository automatically inherits another repository's claims.

Canonical architecture, role allocation, contracts, naming, exact-head org state, and claim boundaries live in [`Aftergraph/after-graph-governance`](https://github.com/Aftergraph/after-graph-governance).
