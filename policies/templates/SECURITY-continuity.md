# Security Policy

This repository carries continuity state or reusable agent behavior. Injected or malformed continuity content is a trust-boundary concern.

## Reporting

Report suspected injection paths, credential exposure, or state-integrity defects privately to the maintainer (@JonasAbde) with a minimal reproduction and affected commit.

## Secrets

No credentials, tokens, or signing material belong in this repository, including in transferred state or skill payloads.

## Supported versions

Only the current `main` branch is maintained.
